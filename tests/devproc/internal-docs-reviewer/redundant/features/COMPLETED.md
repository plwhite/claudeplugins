Added a CSV export control to the reports page (#47): exports the
currently-filtered rows, ISO 8601 dates, unformatted numbers, matching
on-screen columns in the same order, filename `report-<date>.csv`.

Added the ability to apply a tag to multiple selected inventory items at once
(#39), with an undo action available for 30 seconds after applying.
